# algo-daily

매일 알고리즘 미션을 풀고, **이슈 → 커밋 → 푸시 → 코드 리뷰 → 개선 → main PR** 루프를 직접 돌려 보는 학습 저장소입니다. 이 저장소에는 내 풀이만 올립니다. 학습 자료와 미션 원문은 올리지 않습니다.

## 폴더 규칙

```
dayNNN/<섹션ID>/
├─ Main.java      코드 실습: 파일 1개. 클래스가 여러 개면 한 파일 안에 둔다
└─ answer.md      문서 실습: 노트에 쓴 답안
```

- `dayNNN`은 학습 일차(예: `day001`). 섹션ID는 커리큘럼의 ID를 그대로 쓴다.
- 미션 원문 `MISSION.md`는 매일 아침 자동으로 복사되지만 `.gitignore`가 막아서 올라가지 않는다.

## 실행

Gradle 없이 파일 하나를 바로 실행합니다. 한글이 깨지지 않도록 `-Dfile.encoding=UTF-8`을 **항상** 붙입니다.

```
java -Dfile.encoding=UTF-8 day001/<섹션ID>/Main.java
```

프로그래머스에 제출할 때는 로컬 실행용 `main`을 지우고 `Solution` 클래스만 냅니다.

## 이름 규칙 (Jira 이슈 키로 GitHub와 Jira가 연결된다)

| 대상 | 형식 | 예 |
|---|---|---|
| 브랜치 | `ALGO-12-제목` | `ALGO-12-day012` |
| 커밋 | `ALGO-12: 내용` | `ALGO-12: 배열 합 풀이 추가` |
| PR 제목 | `ALGO-12 제목` | `ALGO-12 day012 미션` |

하루 = 이슈 1개 = 브랜치 1개 = PR 1개. `main`에는 PR로만 합칩니다.
